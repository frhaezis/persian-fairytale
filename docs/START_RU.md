# persian fairytale. V2 — запуск и сохранения

Это локальная игра. Браузер показывает окно игры; Python на вашем компьютере запускает учебный код. Публикации, платного API, npm, прав администратора и доступа к биофизическому проекту не требуется.

## Первый запуск

1. Полностью распакуйте архив в удобную папку, например `Документы\Сад точных желаний`. Не запускайте из окна ZIP-архива.
2. Дважды щёлкните `START_GAME.bat`. Откроется браузер с адресом вида `http://127.0.0.1:порт/`.
3. Выберите «Войти в город» или «Продолжить путешествие». Клавиши движения — WASD или стрелки; взаимодействие — E или пробел. Можно идти щелчком мыши. Кнопка «К месту задания» помогает найти текущую цель.

Нужен Windows 10/11 и Python 3.10 или новее; для поставляемого установщика рекомендуются Python 3.10–3.13 и 64-битная Windows. Маленькие модели упражнений работают на CPU, GPU не нужен. Запуск на Windows в среде разработчика не выполнялся; проверенные сценарии и ограничения перечислены в отчёте поставки.

Запуск ищет сохранённый выбор Python, `.venv` рядом с игрой, текущий Python, `py -0p`, PATH и обычные установки Python в реестре Windows. Каждый найденный вариант проверяется настоящим `import torch` и маленькой операцией с тензором. Изменений в существующее окружение нет. Проверка нескольких установок может занять минуту.

Если Python не найден, появится поле для полного пути к `python.exe`. Его можно взять из настроек уже работающего редактора Python. Для ручного выбора запустите в терминале:

```bat
"C:\путь с пробелами\python.exe" "C:\папка игры\launcher.py" --python "C:\путь с пробелами\python.exe"
```

Если `py`/`python` в PATH открывает Microsoft Store или сообщает об отсутствующем Python, используйте эту команду с реальным интерпретатором. При необходимости установите 64-битный Python для текущего пользователя с [python.org](https://www.python.org/downloads/windows/).

## Если PyTorch отсутствует или не загружается

Мир и занятия без PyTorch доступны, но обязательную практику мастерской нужно выполнять настоящим PyTorch. Дважды щёлкните `INSTALL_DEPENDENCIES.bat`: он создаст **отдельную `.venv` в папке игры** и установит CPU PyTorch из официального репозитория. Нужны интернет и свободное место для окружения. Установщик не запускается автоматически и не меняет окружение другой программы.

После успешной установки снова запустите `START_GAME.bat`. При обычных запусках зависимости не переустанавливаются. Если защитник Windows сообщает об отсутствующей системной DLL, сохраните полный текст ошибки из `environment-diagnostics.json`; не скачивайте случайные DLL. Используйте подходящий официальный Python/PyTorch runtime или запасной notebook.

Если локальную среду пока не удалось настроить, откройте `notebooks/practice.ipynb` в Google Colab, например через «Файл → Загрузить блокнот». Основные PyTorch-упражнения доступны там. Это запасная практика, её выполнение не выдаётся за автоматически проверенный локальный запуск; вернувшись в игру, выполните локальные проверки, когда среда будет исправлена.

## Пауза и возвращение

Используйте «Пауза» и «Сохранить и выйти». При потере фокуса игра ставится на паузу. Выход дожидается подтверждения записи. После перезапуска компьютера снова запустите `START_GAME.bat` и выберите «Продолжить».

Сохранения находятся **отдельно от папки игры**:

```text
%LOCALAPPDATA%\PersianFairytaleV2
```

Вставьте эту строку в адресную строку Проводника. Смена порта или замена папки игры не сбрасывают прогресс. Сохраняются шаг диалога, местоположение, задания, черновики, подсказки и завершённые результаты. Незавершённый Python-процесс после закрытия компьютера не возобновляется: его код остаётся, запуск помечается прерванным и требует повтора. Прерванная 15-минутная репетиция отмечается отдельно.

В меню есть экспорт и импорт сохранения. Периодически сохраняйте экспортированный JSON в другую папку. При повреждении основной записи игра предлагает восстановление предыдущей рабочей копии; она не должна начинать новую игру поверх повреждённой записи. Перед ручным восстановлением скопируйте всю папку данных. Экспорт содержит вашу учебную работу и ответы: передавайте его только тем, кому хотите их показать.

## Порт, повторный запуск, журнал

Сервер слушает только `127.0.0.1`; свободный порт выбирается автоматически. Повторный запуск открывает уже работающий сервер. Закрытие вкладки не обязательно завершает сервер: он остаётся локальным процессом до завершения сеанса Windows. Для ручной остановки используйте PID из `%LOCALAPPDATA%\PersianFairytaleV2\server.json` в Диспетчере задач и сначала дождитесь сохранения. Не завершайте все процессы Python: другие программы могут их использовать.

Если браузер не открылся, скопируйте показанный в окне запуска адрес. Если сервер не запустился, откройте `%LOCALAPPDATA%\PersianFairytaleV2\server.log` и `environment-diagnostics.json`. Ничего из этих файлов не отправляется разработчику автоматически. Файлы `launcher.json` и `server.json` содержат технические параметры запуска, а не прогресс.

Для диагностического запуска без браузера:

```bat
py -3 launcher.py --no-browser
```

Для проверки в отдельной тестовой папке:

```bat
py -3 launcher.py --data-dir "%TEMP%\TheGame-Test" --no-browser
```

В Linux: `python3 launcher.py`; данные по умолчанию в `~/.local/share/PersianFairytaleV2`. Можно переопределить папку переменной `THE_GAME_DATA_DIR` или аргументом `--data-dir`.

## Локальная модель

Основной маршрут не требует Qwen. В миссии подключения можно указать папку модели: диагностика читает имена файлов и конфигурацию, ничего в ней не меняет. Папка с весами сама по себе не предоставляет API. Совместимый runtime и его локальный HTTP endpoint подключаются отдельно.

`local_model_example.py` — необязательный пример **настоящей** загрузки совместимой модели формата Transformers, только из локальных файлов. Он требует отдельно установленные `transformers`, `accelerate`, `torch`, может занимать много RAM и запускается только вручную:

```bat
py -3 local_model_example.py "C:\путь\qwen" --max-new-tokens 48
```

Пример не скачивает веса, не исполняет код из репозитория модели и не создаёт HTTP API. Он не подходит для произвольного GGUF. Совместимость с вашей Qwen не проверена. В самой игре остаётся явно обозначенный детерминированный учебный вариант tool calling, позволяющий закончить миссию без модели.

Если ваша папка совместима с Transformers и нужен именно простой локальный HTTP API, в комплекте есть отдельный необязательный CPU-пример:

```bat
py -3 model_adapter.py --serve "C:\путь\qwen" --port 8766
```

Он требует отдельно установленный `transformers` в выбранном интерпретаторе, начинает загрузку только после ручного запуска и читает локальные веса с `trust_remote_code=False`. После сообщения о готовности укажите в игре `http://127.0.0.1:8766/v1`. Для остановки этого примера нажмите Ctrl+C в его окне. Это проверка реального текстового ответа API; она не подтверждает поддержку tool calling конкретной моделью. Если runtime не запускается или памяти не хватает, сохраните диагностику и продолжайте миссию с учебным вариантом.

Учебный Python выполняется отдельным процессом с timeout и остановкой. Это локальный запуск кода с правами вашей учётной записи, поэтому вставляйте только код, который хотите выполнить. Изоляция процесса защищает отзывчивость игры, но не является защитной песочницей для неизвестных программ.


## Новый профиль и агентный цикл V2

Эта редакция использует отдельный профиль PersianFairytaleV2. Старые сохранения не удаляются и не импортируются как завершённые новые уроки. Экспортируйте прогресс через меню игры; JSON другой редакции будет отклонён с объяснением.

В лаборатории локальной модели можно отдельно проверить текстовый ответ API, затем запустить ограниченный агентный цикл с бюджетом 1–4 ответов. Runtime должен отвечать JSON-действиями вида `{"tool":"read_gate","arguments":{"gate":"east"}}` либо `{"answer":"вывод"}`. Протокол и доступные схемы отправляет адаптер. Наблюдения инструментов возвращаются модели; интерфейс показывает фактическую трассу, ошибки и причину остановки. Перед открытием игровых ворот требуется полученный в этом же запуске сигнал.

Подключение поддерживает только локальный HTTP endpoint. Чтение папки весов, ответ API и выполнение агентного цикла — разные операции. Неподходящий JSON, неизвестный инструмент, ошибка API или исчерпание бюджета видны в трассе; игра не заменяет неудачный реальный запуск скрытой имитацией. Детерминированный учебный вариант запускается отдельной кнопкой и подписан.
