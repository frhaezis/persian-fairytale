# Проверка persian fairytale. V2

Дата: 16 ноября 2026. Основная среда: Linux, настоящий PyTorch 2.8.0 CPU, Chromium. Автоматические проверки устанавливают работоспособность, а не человеческое усвоение материала.

| Область | Фактическая проверка |
|---|---|
| Backend, программа, примеры, сохранения, запуск | 61 тест `python -m unittest discover -s tests -p 'test_*.py' -v`. Результат: `artifacts/unit-tests.json` и полный лог. |
| Практика Python/PyTorch | Все 20 эталонных программ на обычных и переносных входах; самостоятельный notebook harness; ошибочные заготовки и граничные случаи. |
| Исполняемая теория | Все 20 кодовых примеров из учебных блоков исполняются. 40 миссий имеют подготовку, пример, переход к практике и карту соответствия проверок объяснениям. |
| Dropout | Три настоящих обучения с одинаковыми исходными условиями, шесть измеренных кривых; другой seed при переносе. Проверено изменение графиков при изменении весов и отказ для неверного eval/no_grad. |
| Агент | Шесть протокольных тестов через loopback HTTP и отдельный проход через UI. Проверены бюджет, проверка аргументов, фактические наблюдения и остановка. Сервер теста — явно обозначенная фикстура, а не LLM. |
| Полный игровой маршрут | Все 40 миссий через действующий UI, все страницы нового объяснения, настоящий Python/PyTorch, финал, reload, перенос и повтор без дублирования наград. `artifacts/browser-v2-route.json`; в отчёте SHA256 проверенных файлов. Ошибок JavaScript нет. |
| Визуал и работа с кодом | Иллюстрации загружаются локально. Проверены окна 1440/1366/1024/800 px, фокус, отсутствие горизонтального переполнения, помощь рядом с редактором, черновик после ошибки/переключения/reload, исправленный запуск и пауза. `artifacts/browser-v2-ui/report.json`. |
| Профиль V2 | Новый отдельный каталог. Импорт старой редакции отклоняется без изменения текущего файла; атомарная запись, checksum, резервная копия и восстановление повреждения проверены. |
| Распакованный архив | `tools/check_release.py` проверяет ZIP и все хеши, запускает копию из пути с пробелами и кириллицей, выполняет настоящий autograd transfer и проверяет повторный запуск сервера. Итог сохраняется в `artifacts/release-check.json` рядом со сборкой. |

Снимки `artifacts/v2-*.png` просмотрены: разные места, портретные сцены, пошаговый урок и график измерений. Переносные проверки и карта объяснений не являются доказательством полного усвоения; особенно сложные темы требуют возвращений и самостоятельных экспериментов.

Ручной содержательный аудит: [MISSION_TEACHING_V2.md](MISSION_TEACHING_V2.md), [DESKTOP_CURRICULUM_V2.md](DESKTOP_CURRICULUM_V2.md). Отдельный обзор семи сложных миссий и их задач также не обнаружил блокирующего разрыва между объяснением и требуемым решением. Это выборочная проверка, не исследование эффективности обучения.

Фактическая Windows-машина недоступна. BAT-файлы и пользовательская локальная модель на Windows не запускались. Веса LLM не загружались, поэтому реальный inference конкретной Qwen не подтверждён. Протокол подключения доступен, основной путь обходится без модели и платных API. Не проверены все возможные программы пользователя или все сочетания браузера и ОС.
