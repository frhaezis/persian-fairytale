# Интерфейс persian fairytale. V2

Windows-версия — иллюстрированное инженерное путешествие по восточному саду. Здесь сохраняется маршрут из 40 поручений с настоящим Python/PyTorch, экспериментами и подключением локального API. Это отдельный опыт от романтической Android-новеллы: спокойное исследование, рабочая тетрадь, код и наблюдения.

## Иллюстрации и места

`static/art/manifest.json` задаёт четыре самостоятельные сцены: сад с водой, мастерская под дождём, ночная обсерватория и терраса над городом. Каждому акту соответствует собственное расположение точек маршрута. Оригинальные иллюстрации и портреты поставляются внутри игры; внешних запросов для визуала нет.

Главное меню и разговоры используют эти иллюстрации. Портрет выбирается по имени говорящего. Путеводный огонёк обозначает положение на иллюстрированной карте; движение не выдаётся за физическую симуляцию изображённой архитектуры. Кнопка «К месту задания» доступна наряду с клавиатурой и мышью. Мир останавливается за диалогом и на паузе; эффект движения можно уменьшить. Обязательной моторной сложности, звука или доступа к микрофону нет.

## Объяснение связано с практикой

Миссия проходит пять этапов: встреча, объяснение, исследование, новый случай, собственный вывод. Поле `teaching` предоставляет цель, необходимые основы, последовательные шаги, разобранный пример, переход к задаче, ошибки и применение в работе. Все разделы доступны через навигацию; учебные примеры сохраняют отступы Python.

Рядом с редактором находятся две опоры: «Код и API» для точного упражнения и «Смысл и теория» для темы миссии. Переключение опор, возврат к полному объяснению и перезагрузка не уничтожают черновик. Чтение объяснения не учитывается как запрос подсказки с ответом. При ошибке запуска можно прямо открыть основы, разобранный пример или переход к задаче.

В m19 иллюстрация Dropout показывает независимую случайную маску, масштабирование на `1 / (1 - p)` и отличие `train()` от `eval()`. После выполнения собственной программы интерфейс строит график из фактического артефакта backend: шесть серий train/validation для p=0, 0.2 и 0.8. Числа и параметры доступны под графиком. Он не подменяется заранее нарисованной успешной кривой.

## Подключённый агент

Учебный детерминированный контур явно подписан. Отдельная необязательная панель вызывает `/api/model/agent`: указанный runtime предлагает действие, backend проверяет его, исполняет разрешённый инструмент и возвращает наблюдение в следующий запрос. Интерфейс показывает шаги, аргументы, наблюдения, причину остановки и полный журнал.

Штатное завершение протокола не объявляется доказательством правильного решения цели. Ошибка API, недопустимое действие и исчерпание бюджета показываются как остановки. Игра не удостоверяет наличие или качество весов за указанным HTTP API. Подключение не заменяет и не подделывает результат основного учебного задания.

## Прогресс и доступность

V2 использует отдельное издание сохранения `persian-v2`; старые профили не становятся автоматически пройденными новыми уроками. Главное меню объясняет разделение. Автосохранение, черновики, принадлежность запуска его миссии, повторение без дублирования наград и экспорт сохраняются. В модальном окне клавиша Tab остаётся внутри окна; у клавиатурного фокуса есть видимая рамка.

Дневник содержит источники, отложенные проверки, пробелы и связь изучаемого с профессией Research Engineer / Agentic LLM. Ссылки — дополнительное чтение, а необходимое объяснение хранится в игре.

## Воспроизводимые проверки

Нужны Python с Playwright, Chromium и выбранный серверный Python с PyTorch:

```bash
THE_GAME_PYTHON=/path/to/python-with-torch python tests/browser_v2_ui.py
THE_GAME_PYTHON=/path/to/python-with-torch python tests/browser_v2_route.py
```

Оба скрипта создают отдельное временное сохранение. Они не записывают решения в профиль игрока и не меняют состояние через внутренние JavaScript-переменные.

- `browser_v2_ui.py`: загрузка оригинального визуала, фокус клавиатуры, намеренная ошибка Python и возврат к объяснению, сохранность черновика, настоящий исправленный запуск, размеры 1440/1366/1024/800 px, отсутствие горизонтального переполнения и внешних запросов, пауза.
- `browser_v2_route.py`: все 40 поручений через реальные элементы интерфейса, все страницы объяснений, Python/PyTorch, артефакт Dropout, финальное сохранение и восстановление, вопрос переноса и повторный запуск кода, отсутствие повторных наград. В m28 локальная HTTP-фикстура проверяет реальную цепочку UI → backend → HTTP → разрешённый инструмент → observation → следующий запрос. Фикстура не является моделью с весами.

Отчёты и снимки находятся в `artifacts/`. Проверки проведены в Linux Chromium. Они не подтверждают запуск на настоящей Windows-машине, качество реальной внешней модели, человеческое понимание или заявленную продолжительность обучения.
