# Происхождение оформления V2

Иллюстрации созданы специально для игры инструментом генерации изображений 16 ноября 2026 года. `static/art/persian-scenes.png` — четыре сцены: сад с каналом, мастерская, обсерватория и терраса. `persian-portraits.png` — портреты Лейлы, Сафара и Нура, включая второе выражение Лейлы. PNG хранятся целиком; manifest задаёт области атласа для отображения. Мир и интерактивные элементы написаны в `static/world.js`. Используются общие мотивы персидской архитектуры; персонажи и сюжет оригинальные.

Шрифты системные; файлы шрифтов, музыка и голоса не поставляются. Картинки Solo Leveling не используются. Материалы RnD, персональный прогресс, документы вакансии, ключи и локальные модели в архив не включены.

Frontend без внешних библиотек; backend на стандартной библиотеке Python. PyTorch и NumPy устанавливаются отдельно из официальных источников и предоставляют собственные лицензии. Объяснения, задания и сюжет написаны для проекта.

## Источники подхода к обучению

Исходный список учебных ресурсов пользователя использован как навигация. Lensa ML (https://lensaml.com/) помогает показывать причинность визуально; Agent Course Mobile (https://agenticai.varasrinivas.com/courses/opensource/mobile/index.html) — связывать определение, пример и ошибку; официальные Python, PyTorch и vLLM — проверять технические детали. Внешняя ссылка не является обязательной предпосылкой для решения: нужные объяснения включены в урок. Наличие бесплатного доступа не означает разрешения копировать учебник или его иллюстрации.

Критически прочитаны GitHub skills: [game-design-review](https://github.com/Yuki001/game-dev-skills/blob/main/skills/game-design-review/SKILL.md) и [2d-games](https://github.com/agent-skills-hub/agent-skills-hub/blob/main/skills/game-development/2d-games/SKILL.md), в том числе рекомендации по обратной связи, доступности и задачам, использующим уже полученную информацию. Исполняемые файлы, установщики и hooks этих репозиториев не запускались и в поставку не входят.
